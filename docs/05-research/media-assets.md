# Registro de recursos multimedia

Registrar cada imagen, modelo, textura, fuente tipográfica y archivo de audio antes de incorporarlo al repositorio.

| Campo | Descripción |
|---|---|
| Identificador | Nombre único del recurso |
| Tipo | Imagen, modelo, textura, audio o fuente |
| Uso previsto | Exposición, arquitectura, interfaz, ambiente, etc. |
| Archivo/ruta | Ruta dentro de `public/assets/` |
| Autor/proveedor | Creador o sitio de origen |
| URL de origen | Enlace de procedencia |
| Licencia/permiso | Licencia y condiciones de uso |
| Atribución requerida | Texto de crédito, si aplica |
| Estado | Pendiente / aprobado / descartado |

No incorporar recursos de terceros sin comprobar que su licencia permite el uso previsto. Mantener los créditos y condiciones de atribución cuando sean obligatorios.
