# Registro de fuentes históricas

## Criterio de selección
Priorizar fuentes primarias o de alta confiabilidad: documentación del fabricante, manuales, fichas técnicas originales, catálogos, archivos institucionales y publicaciones especializadas con referencias verificables.

## Registro por fuente
| Campo | Contenido |
|---|---|
| Equipo relacionado | Modelo de computadora |
| Dato respaldado | Especificación o afirmación histórica |
| Autor/editor | Persona u organización |
| Título | Título de la página o documento |
| URL o referencia | Enlace o referencia bibliográfica |
| Fecha de publicación | Si está disponible |
| Fecha de consulta | Fecha en que el equipo la revisó |
| Nivel de confianza | Alto / medio / pendiente |
| Observaciones | Contradicciones, límites o notas |

## Regla editorial
Toda especificación o afirmación histórica incluida en una ficha debe poder rastrearse hasta una fuente. Registrar discrepancias y resolverlas antes de publicar el contenido.
