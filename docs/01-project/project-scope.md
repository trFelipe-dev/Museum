# Alcance del proyecto

## Incluido en la primera versión
- Museo web tridimensional.
- Vestíbulo, núcleo central, tres salas temáticas y espacio de reflexión/salida.
- Colección de nueve computadoras de 2005 a 2013.
- Imágenes planas de los equipos en marcos tridimensionales; no se requieren modelos 3D completos de cada computadora.
- Placas interactivas y fichas informativas en tres niveles.
- Navegación en primera persona, colisiones y controles adaptados a escritorio y móvil.
- Siete NPCs con comportamientos basados en estados.
- Audio ambiental, subtítulos o alternativas textuales y controles de volumen.
- Optimización, pruebas y publicación web.

## Fuera del alcance inicial
- Backend propio.
- Base de datos externa.
- Registro o cuentas de usuario.
- React y TypeScript.
- IA conversacional para NPCs.
- Modelado 3D completo de las nueve computadoras.

## Condiciones y decisiones pendientes
- Confirmar los dispositivos concretos disponibles para pruebas.
- Confirmar licencias y permisos de imágenes, modelos, fuentes y audio.
- Validar plano y dimensiones finales del museo.
- Medir el rendimiento real y ajustar objetivos gráficos.
- Priorizar el MVP si el tiempo disponible no permite completar todo el alcance.

Los cambios de alcance deberán registrarse y aprobarse por el equipo.
