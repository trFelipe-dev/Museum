# Requisitos iniciales de rendimiento

## Objetivos orientativos
| Plataforma | Objetivo inicial |
|---|---|
| Computadoras compatibles | Aproximadamente 60 FPS |
| Móviles de gama media compatibles | Aproximadamente 30 FPS estables |

Son metas que deberán medirse en dispositivos reales, no garantías previas.

## Perfiles gráficos
- Alto: mayor calidad de sombras y resolución.
- Equilibrado: balance entre calidad y rendimiento; perfil predeterminado.
- Rendimiento: resolución interna y efectos reducidos.

## Aspectos que se medirán
- FPS durante el recorrido.
- Tiempo de carga inicial y de salas.
- Uso de memoria.
- Rendimiento con siete NPCs activos.
- Estabilidad en sesiones prolongadas.

## Optimizaciones a evaluar
Reutilización de geometrías y materiales, control de pixel ratio, reducción selectiva de sombras, optimización de texturas, carga progresiva y actualización menos frecuente de elementos lejanos.
